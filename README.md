# Lulu Resource Governance Dashboard

React dashboard for Portfolio Resource Planning and Early Warning.

## Local Run

```powershell
pnpm install
pnpm run dev
```

Open:

```text
http://localhost:8080
```

## Build

```powershell
pnpm run build
```

## GitHub Pages

This repo includes a GitHub Actions workflow at `.github/workflows/deploy.yml`.
After pushing to GitHub, enable GitHub Pages with source `GitHub Actions`.
